B2 数量徽标 + 单层双列卡片 本次选定

徽标告诉你有几个入口；卡片是一张单层双列清单：「更多」的两个条目就是列表最后两项，逐行铺进同一网格——没有分隔线、不分组、没有第二层弹窗，卡片高度只有 160px。代价是卡片宽到 448px。

这次的落点（B2）：
  1. 行：集合 + 徽标 7 + / + 所选图标与名称 + 右侧 chevron；36px 高，和其它面板行同几何。
  2. 卡片：448×197，两列各 216，中缝 1px 发丝线；每列 4 项、项高 36；已选项左侧 2px 强调条 + 淡底 + 600 字重。
  3. 键盘：↑↓ 列内移动、←→ 换列、Enter 打开、Esc 关闭并回焦到行。
  4. 状态机不变：空态点击不跳转；选中后点击直达该页；悬浮始终可换；折叠成 72px 图标轨时只留集合图标 + 所选图标角标。
超过 8 项时列内滚动而不加第三列；要搜索就在卡片顶部加 32px 搜索条（B 变体原样），宽度不变、高度 +40。A（单列）与 C（宫格）保留作对照。
