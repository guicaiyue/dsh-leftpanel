## 一、改造对象

DSH（DeepSeek Harness）Web 的左侧栏宽 **280px**，从上到下是：品牌条（deepseek HARNESS）→ 36px 高的「新会话」实心按钮 → **面板列表**（`nav`）→ 工作区/会话列表 → 底部 `Remote` / `更多`。

要改造的只有**面板列表**这一段。当前它是一条一行，7 个入口 + 1 个溢出项，`nav` 从 **y=114** 开始、宽 **264px**、总高 **302px**：

| 序号 | 名称 | 图标（16×16 线性图标） |
| --- | --- | --- |
| 1 | 插件 | 风车 |
| 2 | 插件市场 | 商店/网格 |
| 3 | 自动化任务 | 时钟 |
| 4 | 架构建模 | 分支/箭头 |
| 5 | Horon 记忆 | 双竖条 |
| 6 | 上下文洞察 | 面板/文档 |
| 7 | Purge | 盾牌 |
| 8 | 更多（溢出，`span` 不是按钮） | 宫格 |

列表之外的部分（品牌条、新会话、工作区、会话、底部）**一个字都不许改**，它们是背景板，照原样摆着即可。

## 二、要做的功能：把 7 行收成 1 行「集合」

产品语境：这几行插件入口大部分时间用不到，但一旦要进某个插件，又必须能一步点到。所以把**全部面板入口收进一个叫「集合」的行**，用右侧浮层卡片做二级菜单。

### 状态机（必须严格照这个画）

| 状态 | 行长什么样 | 卡片 | 点击行为 |
| --- | --- | --- | --- |
| **S0 空** 从未选过 | `[集合图标] 集合`（无斜杠、无后缀） | 悬浮出现 | **不打开任何页面**，只把卡片打开/保持 |
| **S1 悬浮** | 行本身 hover 底色 | 卡片在行右侧滑出，列出全部 8 项 | 卡片内点击某项 = 选中并打开该页面 |
| **S2 已选** | `[集合图标] 集合 / [所选图标] 所选名称` | 收起 | 点击 = 直接打开所选页面（与今天点那一行的反应完全一致） |
| **S3 已选+悬浮** | 同 S2，行 hover 底色 | 卡片再次出现，列表里给所选打勾 | 点另一项 = 立即切换，行文字同步换 |
| **S4 键盘** | — | 卡片内 `↑/↓` 移动高亮、`Enter` 确认、`Esc` 关闭 | 打开后焦点在卡片首项 |
| **S5 收起栏** 侧栏折叠成图标轨 | 只显示一行：`[集合图标]`，右侧露出所选图标的小角标 | 悬浮出卡片 | 同 S2 |

规则细节：

- 斜杠是**文本分隔符**，颜色用次要/三级文字色（`#adb2b8`），两侧留 6px，不画成竖线、不加边框。
- 斜杠后的**图标 + 名称沿用该项原本的图标与名称**，颜色回到主文字色（`#f9fafb`），与「集合」同字号（14px）。
- 名称最长的是「上下文洞察」（5 个字），行宽 264 内必须放得下 `集合 / 上下文洞察`，**不许截断、不许换行**；实在放不下时可对**后半段**做省略号，但 14px 字号下放得下，所以稿子里应当放得下。
- 「集合」的图标用**集合/堆叠/层叠**语义的线性图标（自绘一个即可，16×16，圆角线帽），**不要**复用现有 8 个里的任何一个。
- 未选中时是否显示数量（如 7）由你判断，但必须给出理由；选定方向后不要两种都留。

### 卡片（浮层）硬约束

- 从行右侧滑出：左边缘 = 侧栏右边缘 +8px（即 **x=288**），顶部与行对齐（`y=114`），**不遮住侧栏本身**。
- 宽 **300–360px** 之间（自定，但要能一行放完「上下文洞察」+ 勾选标记）；高按内容，最多 **8 项 + 顶部标题区**，超出时卡片内滚动而不是撑高。
- 与 DSH 现有浮层同族：圆角 **16px**、内边距 **4–6px**、`0 0 0 0.5px rgba(255,255,255,.16)` 描边 + `0 3px 8px rgba(0,0,0,.04)` + `0 0 20px rgba(0,0,0,.05)` 阴影。
- 卡片项：高 **36px**、圆角 **12px**、左内 8px、图标 16px、图标与文字间距 **6px**、字号 14px；hover 底色 `#ffffff14`；**已选项**给出可辨识的选中态（勾 + 名称加重，或左侧 2px 强调条 + 淡底，二选一，说明理由）。
- 出现/消失 **120ms**（`cubic-bezier(.4,0,.2,1)`），从左侧 4px 位移淡入；`prefers-reduced-motion` 下无动画。

## 四、要产出什么

**一个文件**：`mock/collection.html`，自包含（内联 CSS、内联 SVG 图标，无外部依赖、无 `@import`、无框架、无远程字体）。

页面结构：

1. 顶部一条深/浅色与「方向 A / B / C」两个切换器（纯 CSS/`data-*` + 少量内联 JS 即可，不要引库），并排放 **三个 1440×900 画板**（缩放到 0.62 显示、横排，方便一屏对比），每个画板是一份完整的 DSH 截图级还原：左边栏 280px（品牌条、新会话按钮、集合行、工作区列表、底部）＋ 右侧 1160px 的浅色/深色内容区（用一块「探索未至之境」占位卡和灰底即可，不要抢戏）。
2. 每个画板里**同时**画两个状态：默认（无卡片，S2）和悬浮（卡片展开，S3）——在同一画板里上下摆或左右摆都行，但必须一眼能看出「卡片从哪里出来、出来之后行长什么样」。

**三个方向**（必须真的不同，不是换皮）：

- **A 面包屑行 + 单列卡片**：行 = `集合 / 图标 名称`；卡片是 316px 单列列表，36px 项，右侧勾，底部一行小字提示「↑↓ 选择 · Enter 打开」。稳、最像 DSH 自己的菜单。
- **B 带搜索与分组的卡片**：行 = `集合` + 数量徽标 + 选中后追加 `/ 图标 名称`；卡片 340px，顶部分组（「面板」/「工具」），有搜索框，已选项左侧 2px 强调条 + 淡底。
- **C 宫格卡片**：行 = `集合 / 图标 名称`；卡片是 2 列 × 4 行的图标宫格（图标在左、名称在右，或图标上名称下），选中项整格描边。信息密度最高，代价最大。

每个方向下方附 **三句话**：什么时候最好用 / 代价是什么 / 什么情况下会后悔选它。

3. 文件末尾附 `<section class="spec">` 规格区（照 `reference/` 与上面令牌表写，不要编）：断点（侧栏固定 280，卡片固定右侧偏移，`@media (max-width: 1024px)` 时卡片改为覆盖在侧栏上并加 8px 外边距）、字号阶梯、行高、间距、圆角、阴影、动效时长与缓动、键盘行为、空/满/超长名称三种边界、侧栏折叠 72px 时集合行的形态（图标 + 右上角小角标）。

4. 最后一段回答：**如果只能改 CSS 和一行 HTML（不能改 DOM 结构、不能加节点），这个方向还成不成立**——逐方向回答，不许含糊。
